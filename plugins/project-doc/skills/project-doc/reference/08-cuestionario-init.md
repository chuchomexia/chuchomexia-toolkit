# Cuestionario del workflow init

Máximo cinco preguntas; omitir las que puedan inferirse con confianza.

## 1. Nombre y propósito

Una línea sobre el producto y sus usuarios.

## 2. Topología

¿Repositorio simple o monorepo? Identificar frentes, apps y packages, y si alguno es un repositorio Git independiente.

## 3. Ownership documental

Qué documentos son transversales y qué frente posee producto visual, API, datos, operaciones y flujos.

## 4. Stack y etapa

Tecnologías principales y estado greenfield/existente.

## 5. Reglas no negociables

Restricciones operativas, arquitectónicas o de documentación.

En proyectos existentes, inferir la topología desde el filesystem y pedir confirmación solo si el ownership es ambiguo.
